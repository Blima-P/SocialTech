# Política de segurança

## Versão suportada

A versão suportada é a versão publicada do site, gerada a partir da branch
`main`. Branches de desenvolvimento e versões anteriores não recebem correções
de segurança.

## Como relatar uma vulnerabilidade

Use o
[Private Vulnerability Reporting do GitHub](https://github.com/Blima-P/SocialTech/security/advisories/new)
para enviar o relato de forma privada.

- Não abra uma issue pública para vulnerabilidades.
- Descreva o impacto, os passos para reproduzir e, quando possível, uma sugestão
  de correção.
- Não inclua dados pessoais, credenciais, tokens ou outras informações
  sensíveis.

## Fora de escopo

A infraestrutura e os serviços de terceiros usados pelo projeto não são
mantidos por este repositório. Vulnerabilidades no GoatCounter, Google Forms ou
GitHub Pages devem ser relatadas diretamente aos respectivos fornecedores.
